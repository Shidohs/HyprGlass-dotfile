# Plan de Estudio: Desarrollo de Shells en Wayland con Quickshell

Programa completo para dominar el desarrollo, refactorización y mantenimiento de shells de escritorio Wayland usando Quickshell y QML, aplicado al proyecto `HyprGlass-dotfile`.

## Estructura

| Modulo | Tema | Estado |
|--------|------|--------|
| `module1-wayland-hyprland/` | Fundamentos de Wayland e Hyprland IPC | Teoria + Ejercicios |
| `module2-qml-fundamentals/` | QML y Qt Quick | Teoria + Ejercicios |
| `module3-quickshell-api/` | API de Quickshell | Teoria + Ejercicios |
| `module4-dbus-native/` | Comunicacion DBus nativa (reemplazar bash) | Teoria + Servicios mejorados |
| `module5-mvc-architecture/` | Arquitectura MVC y gestion de estado | Teoria + Patrones refactorizados |
| `module6-testing-debugging/` | Testing, debugging y sandboxing | Teoria + Entorno sandbox |

## Como usar este programa

1. Lee el `README.md` de cada modulo en orden secuencial.
2. Completa los ejercicios en `exercises/` antes de ver las soluciones.
3. Compara tus soluciones con las de `solutions/`.
4. En los modulos 4 y 5, los archivos en `improved-services/` y `refactored-patterns/` son mejoras reales que puedes integrar al proyecto.

## Prerrequisitos

- Conocimientos basicos de Linux y terminal.
- Familiaridad con conceptos de programacion (variables, funciones, objetos).
- Un entorno con Hyprland y Quickshell instalados.
